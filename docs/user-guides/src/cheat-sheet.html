Quick-Start Cheat Sheet

The Structure

Org contains Workspaces contains Channels

  • Public channel — join yourself, anytime.
  • Private channel — a member must add you; invisible to everyone else.
  • DM — private, 1-to-1. Group DM — up to 20 people, private.

Messaging

  • @name — mention a teammate (they're notified). Works in threads too.
  • [[Term]] — link to a shared entity; click to see every mention across your channels.
  • Bold, italic, bold-italic, highlight, and links are recognized automatically as you type.
  • Reply to a message to start a thread (one level deep — no replies-to-replies).
  • Enter sends; Shift+Enter starts a new line in the same message.
You can edit your own message for 15 minutes after sending. Edits are marked (edited), with the full revision history visible to anyone in the conversation — nothing quietly changes.

Inline Tasks

Type anywhere in a message:

- [ ] Do the thing [owner:: @name]

  • Becomes a live, tickable checkbox — no AI, just recognized instantly.
  • Tracked on the workspace Task Dashboard: "Tasks for Me" / "Tasks for Everyone Else."
AI Actions

Summarize Channel — catch up on recent activity fast.

Extract Tasks — pull a checklist from any thread.

Catch Me Up — cross-channel digest: mentions, action items, open questions, decisions.

Semantic Search — search by meaning, not exact words.

Busy? You'll see Queued (position N) — normal, resolves shortly.

Presence

Online · Away · Offline — server-verified, not device-reported.

Notifications

You're notified on @mentions and invitations. Mark individually or all-as-read from the summary.

Your Account

  • Change password anytime (needs current one) — signs out every other session, keeps this one.
  • Update display name anytime, no approval needed.
  • Appearance: Light / Dark / System.
  • DMs auto-archive after 90 days idle by default (configurable, 0 = never) — never deleted; a new message brings one right back.
  • No self-service signup or email password reset — ask an admin.

Joining & Leaving

  • Discoverable workspaces: browse and self-join.
  • Private workspaces/channels: an existing member adds you.
  • Leave any channel, workspace, or org yourself, anytime.
  • Own a workspace? Transfer ownership before you can leave it.

What's Not Here (Yet)

  • No emoji reactions
  • No file/image attachments
  • No read receipts
  • No message pinning

Glossary

  • Entity — a shared [[tag]] for a person, project, or term. Editable metadata, relationships, and an AI "What we know" summary live on its detail page.
  • Thread — flat replies on one message.
  • Semantic search — meaning-based, not keyword.
  • Knowledge Explorer — per-workspace panel showing trending entities and their subject-matter experts.
